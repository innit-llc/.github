# INNIT LLC

We build WolfBoy, which checks what your code does against the law (GDPR, the EU AI Act, CCPA) and against your own privacy policy.

- [WolfBoy](https://github.com/innit-llc/wolfboy): a CLI and Claude Code plugin. The rules check runs on your computer, with no AI, and sends nothing anywhere.
- [Blog](https://innit-llc.com): real privacy fines and settlements, followed from the official documents to the code behind them and the fix.

## How we report

When WolfBoy points at a problem in an open-source project, we report it to the project privately first, through the channel its security policy names, and give the project time to fix it before anything is published. Cases so far: [track record](https://github.com/innit-llc/wolfboy#track-record).
